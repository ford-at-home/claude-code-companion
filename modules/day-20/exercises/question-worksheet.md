# Exercise: Sample Questions Self-Assessment

> Week 3 · Exam preparation

## How to use this

Open the practice/sample questions in the study-guide app. For **each**
question, fill in the analysis below **before** revealing the answer. The point
is to rehearse the elimination technique under realistic conditions — not to
memorize answers.

Copy the template block once per question (in your own file or below).

## Per-question template

```
### Question ___

- Domain I think this tests:
- Two distractors I can eliminate:
    1. [ ]  because:
    2. [ ]  because:
- My answer: [ ]
- One-sentence justification:
- If I got this wrong, which day should I re-read?
```
